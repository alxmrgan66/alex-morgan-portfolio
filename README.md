# Alex Morgan — Fictional Portfolio

This is a fictional portfolio created solely for the Coursera Microsoft web development assignment. It does not represent a real person or real client projects.

## Run locally

Open `index.html` in a browser. No dependencies or build tools are required.

## Publish to GitHub Pages

1. Create a public repository, such as `alex-morgan-portfolio`.
2. Upload the contents of this folder so `index.html` is in the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub to publish the site. Submit the generated `https://USERNAME.github.io/REPOSITORY/` URL to Coursera.

## Grading criteria

- Semantic HTML: header, nav, main, sections, articles, footer and form.
- Accessibility: descriptive image `alt` text, labels, keyboard focus, skip link, live status messages and ARIA attributes.
- CSS: design system, typography, spacing, cards and dark mode.
- JavaScript: theme switch, mobile menu, project filtering and contact form validation.
- Responsive design: breakpoints for tablets and mobile screens.
